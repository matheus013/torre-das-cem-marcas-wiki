# Personagens

Quatro personagens jogáveis, todas até o nível 100. Cada uma tem uma passiva própria, uma arma inicial, uma gema inicial na tecla Q e marcos a cada 10 níveis, em que se escolhe uma opção entre as ofertas do marco.

## Eloa Ferral

| | |
| --- | --- |
| Povo | Velária |
| Família | Ferral |
| Estilo | Condutora |
| Nível máximo | 100 |
| Arma inicial | Filamentos de Forja |
| Gema inicial | [Elo Residual](Gemas-Ativas#elo-residual) |
| Afinidade de armas | Foco 115%, Lanca 85%, Manoplas 80%, Bastao 100% |

**Passiva — Luz Residual.** Acertos e interacoes deixam residuos breves que revelam propriedades e conduzem o proximo efeito entre pontos relacionados.

Recurso: Residuo, até 3.
