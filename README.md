# Aresta — A Torre das Cem Marcas · Wiki

Documentação pública do jogo *Aresta — A Torre das Cem Marcas*: personagens, gemas, inimigos, chefes, biomas, itens, afixos, resistências e dificuldades.

**Leia na [wiki](https://github.com/matheus013/torre-das-cem-marcas-wiki/wiki).** As mesmas páginas estão em [`paginas/`](paginas/Home.md).

As páginas são geradas automaticamente a partir dos dados do jogo; os valores são provisórios e mudam com o balanceamento. Este repositório contém só texto: o código e a arte do jogo não são públicos.
